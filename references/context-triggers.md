# Контекстные Блоки И Триггеры

Используй этот файл, чтобы решать, какие дополнительные разделы включать в итоговый `.md`.

## Правило включения

Включай блок, если в ответах пользователя есть хотя бы один явный триггер или подтверждение по уточняющему вопросу.

## Дистрибуция (только когда влияет на фичу)

Если режим дистрибуции меняет правила выбранной фичи, используй известный режим или уточни его:
- `f2p`
- `premium`
- `hybrid/other`

Правило применения:
- Для `f2p` и `hybrid`: можно активировать все блоки по триггерам.
- Для `premium`: не активируй F2P-специфичные вопросы (IAP, офферы, hard currency, pay shortcut, whale-сегментация, компенсации LiveOps), если пользователь явно не подтвердил эти системы.

## Включать при соответствующем триггере

- Формулы, баланс-переменные и ключи локализации:
  - если есть количественная логика, ресурсы, прогрессия, цены, лимиты
  - если есть любой новый UI-текст, ошибки, подсказки, статусы

## Таблица контекстных триггеров

| Блок | Триггеры в ответах |
|---|---|
| Экономика и награды | валюты, цена, награда, sink/source, дефицит, баланс |
| Монетизация (f2p/hybrid по умолчанию) | офферы, покупка, hard currency, ускорение, pay shortcut |
| FTUE / обучение | новая механика, первый вход, непонятные правила, высокий порог входа |
| LiveOps / оперирование | сезон, ротация, расписание, ручное управление, компенсации |
| Контентная структура | уровни, миссии, пулы наград, коллекции, ротация контента |
| Антиабьюз / антифрод | PvP, рейтинг, фарм, мультиаккаунты, дюпы, эксплуатация лимитов |
| A/B тесты и гипотезы | несколько валидных вариантов решения, неопределенность в дизайне |
| Арт/контент/нарратив | новые ассеты, VFX, анимации, аудио, нарратив, локализация |
| Прогрессия и глубина | долгосрочные цели, mastery, сложность по волнам, unlock-структура |
| Premium: ценность покупки | цена как разовая покупка, value-for-money, replayability, отсутствие IAP, "контент в коробке" |
| Пиллары проекта | риск конфликта с принципами/вижном, необходимость дизайн-чека |
| Сегменты аудитории | разные когорты (new/return/mid/whale/f2p), разный value-путь |
| Тех. ограничения | клиент/сервер разделение, производительность, миграции, совместимость |

## Проверка перед генерацией

1. Зафиксируй список активированных контекстных блоков.
2. Покажи список пользователю в одной короткой сводке.
3. Спроси подтверждение только если есть спорные включения.
4. После подтверждения добавь блоки в итоговый документ.
