# GD Doc Kickoff

Самостоятельный навык интервью по одной выбранной игровой фиче и подготовки её Markdown-документа. Не разворачивает концепты игр и не составляет общий список фич. Другие навыки и поисковые сервисы не требуются.

## Установка

Из PowerShell (Git должен быть установлен):

```powershell
git clone https://github.com/VKSpaz/gd-doc-kickoff.git "$env:USERPROFILE\.agents\skills\gd-doc-kickoff"
```

Перезапустите Codex после установки. Для обновления установленного чистого клона:

```powershell
git -C "$env:USERPROFILE\.agents\skills\gd-doc-kickoff" pull --ff-only
```

## Использование

```text
$gd-doc-kickoff Проведи интервью по фиче ежедневных заданий. По итогам сохрани документ в docs/daily-quests.md.
$gd-doc-kickoff Продолжим интервью по фиче: теперь разберём отмену действия и возврат ресурсов.
$gd-doc-kickoff Прочитай docs/crafting.md и задай вопросы только по пробелам в правилах крафта.
```

Активация только явная. Продолжение текущего интервью не требует повторять команду. Чтение скилла для анализа не активирует его. Навык соблюдает инструкции проекта, не устанавливает инструменты, не создаёт индексы и не запускает другие процессы или скиллы.

Публичная версия в [NullFall Skills](https://github.com/nullfallgames/skills/tree/main/nullfall-gd-doc-kickoff) называется `nullfall-gd-doc-kickoff`; содержание идентично, кроме имени и отображаемого названия. YAML других агентов содержит подсказки; поддержку их policy необходимо проверять в соответствующем клиенте.
